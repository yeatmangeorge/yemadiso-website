# Calculating Macros in Huel

## Calculating Manually
To calculate Huel macros manually, we need to know the nutritional values per serving and scale them to the amount of powder we want to use. This can be found on the back of the package.

For example, if 100g of your Huel flavour contains 30g of protein, 40g of carbohydrates and 15g of fat, then 150g contains 45g of protein, 60g of carbohydrates and 22.5g of fat. Simply multiply each nutritional value by the amount of powder in grams, divided by 100.

This works, but calculating every macro for different serving sizes and Huel flavours can become tedious.

## MacroShake

Luckily there is a tool that can do this all for us! It's an app called MacroShake. They've done the hard work for us, so we can simply select our Huel powder, enter how much of a macro we want and it will calculate it for us.
